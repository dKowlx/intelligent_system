# Теория маршрута и контекстные изменения времени

Дата: 15 ноября 2026 года. Публичный сервис: https://navigator.136-234-80-52.sslip.io/.

## Изменения

- Срок отображается в одну строку, включая мобильную ширину 320 px.
- Фраза «да, подстрой всё» использует последнюю пользовательскую оценку из текущей истории. Диапазон 3–4 часа сохраняется как 180–240 минут; расписание использует 240 минут. Текст ассистента, процитированные инструкции и запросы о подшагах не авторизуют массовую правку родительских действий.
- Предложение проверяется до сохранения. Применение выполняется кнопкой, с контролем версии карточки/плана. Прогресс, зависимости, занятые дни и выбранный резерв сохраняются.
- В схеме к действиям прикреплены отдельные раскрываемые блоки теории. Это схема рабочего процесса с аннотациями, а не полный BPMN-редактор.
- GET `/api/assignments/{id}/theory` возвращает локальную/сохранённую подборку; POST запускает ограниченный бесплатный поиск Wikipedia: до пяти коротких тем, три запроса одновременно, общий бюджет 16 секунд. Содержимое файлов не отправляется поисковику; отправляется короткая тема действия.
- `search_materials` в собственном MCP получил необязательный `include_theory`. Объяснения в чате могут использовать найденные выдержки; исследования продуктивности запрашиваются только по соответствующей теме, а не при изменении времени.
- Выдержки имеют происхождение, автора/лицензию и оригинальную ссылку. Внешняя теория не подменяет требования проекта или точное условие упражнения. Упоминание учебника не означает наличие его текста.
