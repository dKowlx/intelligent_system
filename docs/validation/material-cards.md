# Компактные материалы — 14 ноября 2026

В списке материалов одна карточка соответствует одному PDF или одному текстовому
описанию. Показываются название, короткая выдержка до 180 символов и тип материала;
повторный список файлов и длинная сетка извлечённых фрагментов удалены.
Описание — выдержка сохранённого текста, без нового AI-запроса или новых фактов.

PDF группируются по идентификатору документа или URL, а не по имени. Текстовые
материалы группируются по последовательности их пронумерованных фрагментов;
начало новой последовательности сохраняет отдельную карточку даже при равном имени.
Поиск показывает одну карточку на материал и ссылки на найденные страницы.

Нажатие на карточку PDF открывает исходный файл во встроенном просмотре с переходом
на выбранную страницу и ссылкой открытия в новой вкладке. Текстовое описание
открывается полностью. Ссылки на точные источники в ответах ассистента и сами
исходные фрагменты остаются прежними. Закрытие освобождает PDF-просмотр; доступ
к файлам по-прежнему проверяет backend по браузерной сессии.

Проверки: 80 Node-тестов; Chrome на локальном offline-сервере — группировка
многостраничного PDF, два одноимённых файла, независимые одноимённые тексты,
полный текст, открытие оригинала PDF, страница 5 из поиска, Escape и адаптивность
на 320/390/1440 px в светлой и тёмной темах. Внешние запросы в локальной проверке
блокировались, ошибок JavaScript не обнаружено. Материалы проверки:
`var/material-cards-qa/`, `var/material-cards-web.log`.

Платные запросы модели и изменения Git не выполнялись.
