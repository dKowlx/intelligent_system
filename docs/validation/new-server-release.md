## Найденные и исправленные ошибки

1. DeepSeek исчерпал 6000, затем 10000 выходных токенов до завершения карточки.
   `reasoning_effort=low` не устранил это на контрольном проекте. Короткий запрос
   с `none` вернул корректный JSON без reasoning-токенов; повторный разбор проекта
   использовал 2404 выходных токена и прошёл валидацию.
2. Чат возвращал строки в `facts` и неподдерживаемый `answer_basis`. Для grounded
   пути добавлена явная схема с `facts=[]`, допустимыми основаниями и операциями.
   Валидация не ослаблена. Ответ и изменение плана проверены повторно.
3. Безусловная инструкция сообщить о недоступности поиска создавала ложное
   замечание при успешном hybrid retrieval. Сообщение теперь требуется только
   при фактическом статусе ошибки; последующий живой ответ прошёл проверку.
4. `.dockerignore` исключал CLI индексации. Для единственного серверного скрипта
   добавлено исключение, Docker-образ пересобран и запущен.

Две остановки браузерного сценария относились к проверяющему скрипту:
минимум три подшага ошибочно требовался даже у короткой задачи; PDF-селектор
искал относительный href, тогда как приложение использует абсолютный same-origin URL.
Исправлены критерии проверки, дополнительная генерация для этих исправлений не нужна.

## Оценка результата и границы

Контрольный проект — исследование онбординга: три интервью, три приоритизированные
проблемы с наблюдениями, прототип из пяти экранов, три проверки, отчёт с ограничениями.
Все четыре требования связаны с действиями, порядок зависимостей осмысленный,
у действий есть результат и критерий готовности; суммы подшагов совпадают с задачами.
Общая оценка модели — 810 минут. Это предположение, не измеренная трудоёмкость.
Некоторые шаги прототипа ещё общие («экран 1»); содержание экранов требует уточнения.
Доступность по дням подтверждается отдельно в интерфейсе, а не извлекается
автоматически из свободного описания занятости.

Исследовательский ответ ссылается на релевантные фрагменты и отмечает ограничения
переноса результатов. Он не задаёт универсальный цикл 25/5. Эта ограниченная
выборка не заменяет оценку качества разных проектов и не доказывает рост продуктивности.

Тестировался перезапуск контейнера, а не полная перезагрузка нового VPS.
Backup восстановлен на уровне файлов и SQLite; запуск отдельного восстановленного
веб-экземпляра не проводился. Ежедневный systemd timer включён на 03:15–03:20 МСК;
первый ручной запуск сервиса копирования успешен. Архивы хранятся на том же VPS.
Намеренно выключенное приложение резервирование не запускает.
