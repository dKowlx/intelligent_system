# Запись прогресса и компактная декомпозиция — 16 ноября 2026

## Причины и исправление

Запрос «я разобрал объем и критерии, потратил на это 120 минут, заполни эти пункты»
завершался `context_limit_exceeded` до вызова модели. В контекст одновременно
попадали полные задачи из карточки и их копии из сохранённого плана; найденные
выдержки увеличивали суммарный объём сверх ограничения 32 000 символов.

Теперь актуальные задачи сохранённого плана передаются один раз в `card.tasks`.
Контекст плана содержит ссылку `tasks_ref`; ID, подшаги, длительности, прогресс,
зависимости и источники сохранены полностью. JSON уплотнён без обрезки данных.
Лимит не повышался.

Дополнительно «заполни» распознаётся как просьба об изменении. Оба пути провайдера
получают правило записывать потраченное время в `actual_minutes`, сохраняя
плановую оценку. Неоднозначное действие и распределение общего времени требуют
уточнения. Сохранение по-прежнему происходит только через «Применить».

Из редактора действий удалена группа «Какие требования покрывает».
Связи `requirement_ids` сохраняются при редактировании и продолжают использоваться
в проверках и аналитике. Сообщения при удалении связанного требования больше
не предлагают воспользоваться скрытым редактором связей.

  обращения к тестовому провайдеру. Отдельная HTTP-регрессия воспроизвела отказ
  `invalid_action_proposal` из-за слова «заполни».
