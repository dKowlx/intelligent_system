# История чатов, горизонтальная схема и оценка времени

Дата: 15 ноября 2026 года. Изменения опубликованы на
https://navigator.136-234-80-52.sslip.io/.

## Изменённое поведение

- Схема показывает все действия горизонтально в стабильном топологическом порядке. Реальные зависимости не заменяются придуманными; последовательность независимых действий остаётся визуальной последовательностью. Доступна горизонтальная прокрутка.
- Под ассистентом находится история разговоров: создание, выбор и удаление с подтверждением. Сообщения и ошибки хранятся в SQLite, привязаны к проекту и браузерному пространству. Переключение проекта, reload и перезапуск приложения не очищают сохранённые разговоры. Старые сообщения, потерянные до этого обновления, не восстанавливаются.
- В модель передаются последние три пары сообщений выбранного разговора с ограничением длины; присланная клиентом история не заменяет серверную. Сохранённые предложения плана доступны для чтения, но не содержат действующих Apply-токенов. Старые веб-цитаты читаются из снимка сообщения даже после вытеснения поискового кэша.
- Два параллельных запроса в одном чате не смешиваются: второй получает явный статус занятости. Прерывание записывается как ошибка; при старте сервиса незавершённые запросы освобождаются. Текущий запуск однопроцессный.
- Фраза «ты можешь сделать изменения, что для каждого блока сделать 240 минут, потому что за 60 я не успею» создаёт локальное проверенное предложение по 240 минут. Узкое пояснение причины отделено от команды; запреты неоднозначных, цитируемых и противоречащих изменений сохранены.
- Вопрос о предыдущем сохранённом сбое получает понятное локальное объяснение. Ответ по плану может ссылаться на действительно полученную общую теорию/исследование без ошибочного смешения с фактами документа.
- Поля дней и обычного дневного лимита имеют одинаковые ширину, высоту и положение.
- «Уточнить оценки с ИИ» запускает явную переоценку сохранённого плана. Правила требуют объёма × предполагаемого темпа, подготовки, основной работы, проверки, диапазона, допущений и сопоставимого фактического темпа. Одинаковые минуты не заменяются случайными числами. Ручной шаблон явно не откалиброван; существующие пользовательские планы не меняются скрыто.
- MCP получает до трёх отдельных содержательных тем для бесплатного поиска Wikipedia; общий шаблон «Решить все задачи из списка второй части» пропускается. Интернет поясняет операции, а не подтверждает длительность конкретного пользователя. AI-оценки сохраняют `estimate` и своё основание через доверенные серверные метаданные предложения.
