# Рабочее пространство: интерфейс и локальный путь

Проверено 14 ноября 2026. Реальный headless Chrome и FastAPI/SQLite на
`127.0.0.1:8014`, отдельная база `var/workspace-v3-qa/study.db`.
Settings заданы явно: offline, пустые API URL/key/model. `.env` не читался.
Ни платных LLM-вызовов, ни SSH, ни публикации не было.

## Результат

- `node --test tests/web/*.test.cjs`: **73 теста прошли**.
- `tools/check_workspace_v3.cjs`: **17 проверок** с реальным локальным backend;
  **40 сочетаний** пяти вкладок, светлой/тёмной тем и ширин 320, 390, 1024, 1440 px.
- 0 горизонтальных переполнений страницы, 0 ошибок JavaScript/консоли,
  0 внешних сетевых запросов. Визуально проверены аналитика desktop/mobile,
  просмотр источника, план и предложение ассистента на снимках.
- Автономный HTML, в том числе раскрытые редакторы действий и перенос ZIP,
  проверен отдельно: [отчёт макета](clickable-demo.md).

Путь браузерной проверки: создание рабочего примера → карточка → расчёт
470/450/20 минут → выполнение действия с фактом 50 минут → аналитика →
добавление текста со ссылкой → открытие текста в окне → добавление настоящего
авторского PDF в текстовый проект → ссылка на исходный PDF → команда завершить
действие → предложение без записи → кнопка применения → обновлённый план →
перезагрузка → сохранённая завершённость и аналитика.

Для backend использовался детерминированный провайдер, точная команда завершения
по ID; это проверяет цепочку MCP/валидации/применения, но не качество живого AI.
Полный backend-набор и mock-вызовы модели: [362 теста](workspace-v3-backend.md).

## Исправления по проверкам

- Первоначальные unit-ожидания обзора как стартовой страницы заменены
  согласованным открытием карточки и новым порядком пяти вкладок.
- В браузерном тесте окна источника ожидание открытия диалога дополнено
  ожиданием асинхронно загруженного оригинала; ошибки приложения не было.
- На мобильной ширине кнопка обновления аналитики перенесена под заголовок;
  её текст не разрывается. У графика одного завершённого действия нет повторных
  целочисленных подписей оси.
- Неизвестный факт не рисуется как нулевая точка. Частичный итог отмечен отдельно;
  первая запись — исходный снимок, не выдуманный дневной прирост.
- Редактирование карточки/декомпозиции блокируется до сохранения правок прогресса.
  Во время редактирования карточки поля прогресса недоступны; это исключает
  перезапись несохранённого ввода при подтверждении карточки.
- Ближайшее действие в обзоре и плане выбирается одинаково: зависимости перед
  зависимыми действиями, высокий приоритет распространяется на предпосылки.

## Воспроизведение

```sh
NODE_PATH=/path/to/node_modules node tools/check_workspace_v3.cjs
```

Нужен локальный сервер на 8014 с отдельной offline-базой и файл
`var/workspace-v3-qa/qa-source.pdf` — авторский одностраничный тестовый PDF.
Исходный helper для его создания: `text_pdf` в `tests/app/test_ingestion.py`.
Отчёт и снимки: `var/workspace-v3-qa/browser/`. Все эти данные исключены из Git.
