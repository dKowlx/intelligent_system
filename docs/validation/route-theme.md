# Схема маршрута и темы: локальная проверка

Дата: 9 ноября 2026. Уровень: реальный Chrome + локальный backend в режиме
`offline`, отдельная SQLite `var/route-theme-qa/study.db`, порт 8013.
Запросы браузера вне origin локального сервера блокировались. Ключи и настройки
LLM не передавались; платная модель, SSH и опубликованный сервис не проверялись.

Проверяющий сценарий: `tools/check_route_theme_ui.cjs`. Он создаёт проект через
форму примера, подтверждает карточку и сохраняет план через настоящий backend.
Отдельный фиксированный набор из четырёх действий передаётся настоящему
браузерному модулю маршрута для проверки ветвления и слияния; этот набор не
выдаётся за генерацию модели или серверный расчёт.

Автоматические проверки после интеграции:

- `node --test tests/web/*.test.cjs` — **65/65**, включая раскладку и ошибки
  графа, тему, хранение предпочтений и связь схемы с состоянием приложения.
- `pytest tests/app/test_project_workspace.py tests/app/test_api.py -q` —
  **20 passed**, 7,14 с, локальный offline backend и страницы источников.
- `pytest tests/app/test_provider_analysis.py -q` — **30 passed**, 0,65 с,
  подменённые ответы провайдера; внешние запросы не выполнялись.

Итоговый прогон: **61 проверка прошла**, 32 сочетания темы/ширины/раздела,
ошибок JavaScript и console — 0. Изолированный сервер 8013 после проверки остановлен.

Проверены светлая и тёмная темы, сохранение после reload, системная тема и
смена системного предпочтения, оформление страницы текстового источника.
Обзор, карточка, план и чат проверены на 320, 390, 768 и 1440 px в обеих темах:
32 сочетания без горизонтального переполнения страницы. Внутренняя прокрутка
схемы допустима. Узлы открывают подробности с клавиатуры и мышью, CTA ведёт
к редактированию действия; работают масштаб, сброс и альтернативный список.

Даты проверены отдельно: действие на двух днях показывает оба дня; устаревший
расчёт скрывает прежние даты; неизвестные даты остаются номерами дней.
Для цепочки из 20 действий на 390 px кнопка «Вместить» даёт ширину canvas 310 px
при viewport 326 px, ширина документа — 390 px. Reduced motion отключает smooth
scroll. Измеренный минимальный контраст восьми ключевых пар текста и фона:
4,89:1 в светлой теме, 7,45:1 в тёмной. Это выборочная проверка, не полный WCAG-аудит.

Визуально просмотрены реальные screenshots схемы, ветвления/слияния, чата и
мобильной карточки. Узлы и стрелки различимы, длинные названия ограничены внутри
узлов и раскрываются в подробностях. На мобильном схема прокручивается внутри
панели, поля карточки остаются в ширине страницы.

Во время QA выявлено, что выбор «Список» сохранялся при навигации, но сбрасывался
после reload; добавлено сохранение предпочтения. При серии повторных прогонов
сработал штатный HTTP 429 на сохранении плана; повтор сделан после перезапуска
только изолированного сервера. Проверка системной темы ожидает асинхронное событие
`matchMedia`, а не считывает атрибут немедленно.

Повторение на отдельном offline-сервере (без чтения `.env`):

```sh
env -u LLM_API_KEY -u LLM_BASE_URL -u LLM_MODEL STUDYNAV_MODE=offline \
  STUDYNAV_DB_PATH=var/route-theme-qa/study.db PORT=8013 \
  .venv/bin/python -m studynavigator
NODE_PATH=/path/to/node_modules \
  node tools/check_route_theme_ui.cjs
```
