# Автономное кликабельное демо

Проверено 14 ноября 2026 в настоящем headless Google Chrome через Playwright.
HTML открывался по `file://`, без сервера. HTTP(S)-запросы блокировались и
учитывались: **0 попыток**, 0 ошибок JavaScript и консоли. Платные API и SSH
не использовались.

Артефакты: `var/share/project-navigator-demo.html` и одноимённый ZIP.
Сборка: `.venv/bin/python tools/build_clickable_demo.py`.
HTML содержит все CSS/JS внутри файла. Сборщик читает только явно перечисленные
файлы интерфейса и авторские примеры; `.env`, БД и пользовательские загрузки
в сборку не входят. ZIP содержит HTML и `START_HERE.txt`; совпадение HTML в ZIP
с исходным артефактом проверено побайтово.

В интерфейсе нет верхней плашки демо, кнопки сброса и постоянных напоминаний
о неподключённой модели. Сопроводительный `START_HERE.txt` прямо описывает
авторские примеры, имитацию чата и хранение изменений в памяти до перезагрузки.

```sh
node --test tests/web/demo-runtime.test.cjs
NODE_PATH=/path/to/node_modules node tools/check_clickable_demo.cjs
# Для перемещённой копии:
DEMO_QA_OUTPUT=var/clickable-demo-qa-relocated NODE_PATH=/path/to/node_modules node tools/check_clickable_demo.cjs /путь/к/project-navigator-demo.html
```

Оба браузерных прогона прошли: **56 проверок**, 24 сочетания темы/ширины/экрана.
ZIP извлечён в отдельную папку `/private/tmp/navigator-demo-v3-final-4eo54d0w/`;
полный сценарий повторён оттуда. Отчёты и по 30 снимков находятся в
`var/clickable-demo-qa/` и `var/clickable-demo-qa-relocated/`.

Проверены:

- Два авторских проекта; эталонные 470 минут работы / 450 доступных / 20 дефицита.
- Пять представлений — о проекте, ассистент, обзор, действия и план, аналитика —
  при ширинах 390 и 1440 px, в светлой и тёмной темах. Переполнения страницы нет.
- Раскрытая декомпозиция с первыми двумя открытыми действиями при 320 и 390 px
  в обеих темах: нет горизонтального переполнения, снимки сохранены.
- Создание проекта при обеих ширинах и темах, ручное подтверждение карточки и план.
- Три варианта темы, сохранение выбранной темы после перезагрузки файла.
- Узел графа, ожидаемый результат, критерий готовности и переход к плану.
- Занятый день, резерв, завершённость, пересчёт и сохранение при переходах.
- Добавление текста со ссылкой; общий диалог источника с краткой выдержкой,
  сохранённым фрагментом и ссылкой на оригинальную статью.
- Изменение приоритета внутри декомпозиции и сохранение карточки.
- Два графика аналитики на сохранённой авторской истории, сравнение оценок и факта.
- Команда «отметь Собрать кликабельный прототип выполненным» создаёт предложение;
  до нажатия «Применить к плану» данные не меняются, после нажатия план обновляется.
- Перезагрузка возвращает два исходных проекта, начальный прогресс и резерв.

Шесть Node-тестов адаптера прошли. Они проверяют расчёт, валидацию, конфликты
версий, материалы/источники, историю аналитики и применение предложения только
при явном `apply: true`, с запретом повторного применения. Неуказанное время
остаётся `null`; первая запись — исходный снимок без прироста, даты относятся
к часовому поясу Europe/Moscow.

Это автономный файл: чат использует детерминированную сводку карточки и один
явно описанный сценарий команды, а не подключённую модель. История исходных
проектов авторская; новые записи возникают при фактических сохранениях плана.
PDF в автономном файле не обрабатывается: попытка возвращает понятную ошибку.
Настоящая модель, MCP и хостинг этим прогоном не проверялись. Поведение хранения
темы на `file://` в других браузерах отдельно не проверялось.
