# Рабочее пространство Project Navigator

Полный редизайн, 9 ноября 2026. Прежняя версия сохраняла структуру длинной
анкеты: навигация только прокручивала её, а ближайшее действие находилось
ниже настроек. Новый интерфейс строится вокруг выполнения проекта.

## Основания

Применены [frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
из официального репозитория Anthropic и локальный `design-critique`.
Из первого взяты предметное визуальное направление, компактная система токенов
и обязательная самопроверка макета; из второго — оценка иерархии и удобства.

Референсы: [Linear Projects](https://linear.app/docs/projects) — компактный
проект с результатом и связанными действиями;
[Sunsama Workspace Navigation](https://help.sunsama.com/docs/usage-guides/workspace-navigation/)
— отдельные режимы планирования и выполнения;
[Akiflow Task Management](https://product.akiflow.com/help/collections/8429656-task-management)
— быстрые действия рядом с объектом. Команды, интеграции, календари по часам
и прочие отсутствующие функции не изображаются.

## Направление

Светлое рабочее поле, белая боковая панель, синий акцент, компактный гротеск.
Типографика: системный Segoe UI / SF Pro для кириллицы, 14px основной текст,
26–32px название проекта, 23px действие в фокусе, 10–13px вторичная информация.
Без внешних шрифтов, картинок и runtime-запросов к референсам.

Токены: Canvas `#f5f7fb`, Surface `#ffffff`, Ink `#19243b`, Muted `#5e6d86`,
Action `#365de8`, Focus `#192e70`. Предупреждение имеет отдельный янтарный тон.
Сетка: sidebar 232px + гибкое поле до 1480px; отступы 8/12/16/24/32.
Текст выровнен влево, числа — по единым колонкам. Не все элементы превращаются
в одинаковые карточки: список действий, фокус и исходные данные различаются.

## Структура

```text
Проекты          Название проекта                         Срок
Новый проект     Обзор | Действия и план | О проекте | Ассистент
Список           Выполнено / осталось работы / доступно / дефицит
                 ┌ Ближайшее действие ──────┬ Вместимость ──────┐
                 │ Результат и готовность  │ Доступность по дням│
                 │ Открыть действие        │ Изменить время    │
                 ├ Маршрут проекта ────────┼ Итоговый результат┤
                 │ Связанные шаги          │ Требования        │
                 └─────────────────────────┴───────────────────┘
```

* Обзор — основной экран после открытия готового проекта. Все числа из
  сохранённых данных; отсутствие плана объясняется отдельным состоянием.
* Действия и план — строки работы, доступность и расписание. Сохранение явно,
  рядом с несохранёнными изменениями. Остаток и факт остаются разными полями.
* О проекте — цель, требования, редактирование действий и материалы. Длинные
  подробности раскрываются по запросу; форма не доминирует в ежедневной работе.
* Ассистент — разговор и источники рядом; большая собственная область прокрутки.
* Новый проект — отдельный стартовый экран с текстом/PDF и помеченным примером
  будущего маршрута. Нет пустых панелей ещё не созданного проекта.

Вкладки переключают видимость, сохраняя DOM и черновики. Автоматическое
перекидывание вкладок от фокуса/прокрутки удаляется. Анимация 160–180ms при переключении представления, появлении сообщения
и смене состояния навигации; `prefers-reduced-motion` отключает движение.
Мобильный экран сохраняет функции и читаемые названия; горизонтальный выход
основного содержимого недопустим.

## Приёмка

Проверить создание, подтверждение, отдельные представления, сохранение и
восстановление прогресса, несохранённые правки, поиск, источники и offline-чат.
Проверить 1440/1280/1024/768/390/360/320px, фокус, отсутствие перекрытий и
вёрстку длинных названий. Новый дизайн сравнивается со снимками предыдущего.
LLM API, SSH, deploy и commit в эту работу не входят.


## Диаграмма и тёмная тема

В обзоре маршрут вынесен на полную ширину: переключатель схемы/списка,
масштаб, соединённые блоки и подробности действия. Высота области соответствует
размеру графа; горизонтальное движение остаётся внутри неё. В длинных связях
стрелки обходят карточки.

Добавлена тёмная палитра на тех же семантических переменных и системный режим.
Переключатель доступен в боковой панели и на мобильном экране. Подробнее:
[маршрут и оформление](route-and-theme.md).
