# Рабочее пространство Project Navigator v3

Локальное обновление сохраняет материалы, план, приоритеты и записанный факт отдельно от ответов модели. Добавление источника не перезаписывает подтверждённую карточку или прогресс. Подготовленный общий пример доступен для чтения; изменения разрешены только владельцу приватного проекта по cookie сессии.

## Запуск и проверка

Python 3.12; из корня репозитория:

```sh
uv sync --locked --extra dev
STUDYNAV_MODE=offline .venv/bin/python -m studynavigator
.venv/bin/python -m pytest tests/app/test_workspace_data_v3.py -q
```

Полная настройка и команды — в [README](../README.md). Offline не подтверждает работу подключённой модели. API-ключи нужны только серверу для явно настроенного live-режима; для этой локальной проверки платные запросы и SSH не требуются.

## Материалы и просмотр источника

`POST /api/assignments/{id}/materials` принимает JSON:

```json
{"title":"Статья", "text":"Вставленный пользователем текст статьи", "external_url":"https://example.org/article"}
```

`external_url` необязателен; допускается HTTP(S) без имени пользователя/пароля. Сервер сохраняет ссылку и индексирует переданный текст, но не скачивает URL. Ссылка сама по себе не доказывает содержание статьи.

Тот же маршрут принимает multipart: `files` (1–3 PDF) и необязательный `title`. Пределы проверяются для всего проекта после добавления: до 3 PDF, 10 MiB, 100 страниц и 100 000 символов индексируемого текста. Нужен текстовый слой; OCR и DOCX не поддерживаются. Некорректный комплект отклоняется целиком, его новые файлы удаляются. Ответ `201`: `{assignment: ...}`. Чужой проект возвращает `404`, общий пример — `403`, превышение лимита или неверные поля — `422`/`413`.

`GET /api/assignments/{id}/materials?q=...` возвращает `{matches:[...]}`. `GET /api/sources/{source_id}` возвращает **сам объект источника**, без обёртки. Сохраняются `source_id`, `title`, `page`, `section`, `excerpt`, `url`; добавлены `kind`, `preview` (исходный фрагмент), `summary` (первые 240 символов, не AI-пересказ), `external_url` и `file_url`. Отсутствующие внешняя ссылка/оригинал равны `null`; для PDF `file_url` ведёт к защищённому оригиналу. Метаданные источника, PDF и поиск сохраняют изоляцию владельца.

`materials_revision` увеличивается при добавлении. Если материалы изменились во время AI-разбора, сохранение устаревшего результата отклоняется с `409`. Для повторного анализа необходимо явное действие пользователя.

Встроенная библиотека исследовательских обзоров удалена. Справочные статьи
пользователя не предзагружены; добавление текста, ссылки с сохранённым текстом
или PDF через этот маршрут сохранено. Одна ссылка без текста не пополняет
проверяемую базу знаний содержимым статьи.

## План, факт и аналитика

План сохраняется через существующий `PUT /api/assignments/{id}/plan` с `revision`, `card_revision`, `tasks`, `availability`, `start_date`, `reserve_percent`. Конкурирующее сохранение отклоняется с `409`. Приоритет и его основание берутся из подтверждённой карточки; браузер не подменяет происхождение оценки.

Действие может содержать `substeps` (до 8): `id`, `title`, `minutes`,
`done_when`. Идентификаторы уникальны внутри действия; длительности положительные,
их сумма приводится к оценке родителя. При изменении оценки минуты распределяются
пропорционально с минимумом в одну минуту на подшаг; слишком малая оценка
отклоняется. Старые действия без подшагов остаются допустимыми.

Дневные слоты содержат только пересечение подшагов с выделенным временем.
Переходящий подшаг сохраняет ID и критерий, получает `total_minutes` и признаки
`continued`/`continues`; `minutes` показывает часть времени именно этого дня.
Число пунктов не выравнивается до пяти: нулевой бюджет и отсутствие оставшейся
работы дают пустой день. Расписание задаёт точные длительности в минутах, но
не часы начала и окончания. Отметка завершения и факт остаются у родительского
действия; отдельные статусы подшагов пока не ведутся.

`GET /api/assignments/{id}/analytics` возвращает `{analytics: ...}`:

- `totals`: текущая сумма оценок, количество завершённых действий, известное фактическое время и количество действий с известным/неизвестным фактом. `actual_minutes` равен `null`, если факт не указан ни для одной задачи; `recorded_actual_minutes` — сумма только введённых значений. Частичная сумма не означает, что неизвестное время равно нулю.
- `tasks`: текущая оценка, `actual_minutes` (`null` при отсутствии), разность с текущей оценкой `delta_minutes`, первая сохранённая оценка `baseline_estimated_minutes` и разность с ней `baseline_delta_minutes`. Для старого плана без истории базовая оценка неизвестна. `0` минут — явно введённый ноль.
- `history`: неизменяемые снимки при успешном сохранении, `recorded_at` с зоной, календарная `date` в `Europe/Moscow`, накопленные значения и подписанные изменения относительно предыдущего снимка. Первая запись имеет `baseline:true` и изменения `null`. Отрицательное изменение отмечено `correction:true`.

Это история **записи накопленного факта**, а не поминутный таймер или доказательство работы в конкретный день. Исправления факта не стирают прежние снимки. Оценка никогда автоматически не становится фактическим временем. Изменение текущей оценки не меняет сохранённую базовую оценку. Удаление проекта удаляет его историю.

## Предложения ассистента

MCP `get_assignment` включает `project_context:{plan,analytics}`. Контекст модели сокращается до текущего плана и последних 10 снимков; факт пользователя отделён от утверждений источников.

Ответ `/api/chat` может содержать проверенное `action_proposal` с `summary`, `operations`, `proposal_id`, `card_revision`, `plan_revision`. Это предварительный просмотр. Изменение выполняет только отдельный запрос:

```json
{"proposal_id":"серверный-токен", "card_revision":1, "plan_revision":2, "apply":true}
```

Маршрут: `POST /api/assignments/{id}/assistant-actions`; ответ `{assignment,plan}`. Сервер хранит исходное предложение и не принимает произвольные операции из браузера. Токен привязан к сессии и проекту, живёт 15 минут, применяется один раз; перезапуск приложения сбрасывает неподтверждённые токены. Изменение карточки, плана или материалов после предложения приводит к `409` без частичной записи. Карточка, план и снимок факта обновляются одной SQLite-транзакцией.

Сохранность приватных данных зависит от локальной БД/каталога файлов и cookie; полноценной учётной записи и восстановления доступа нет.

### Представление материалов

Список показывает одну компактную карточку на PDF или текстовое описание.
Длинные извлечённые фрагменты в списке не повторяются: PDF открывается во встроенном
просмотре, описание — целиком в окне чтения. Поиск сохраняет ссылки на найденные
страницы PDF. Короткое описание карточки является выдержкой текста без генерации
новых фактов моделью; источники цитат ассистента остаются точными фрагментами.

### Обычные реплики в чате

Приветствия, благодарности и вопросы о возможностях сервиса получают локальный
ответ без LLM и без ссылок на материалы. `response_origin=local` и
`answer_basis=conversation` добавляет только приложение, не модель.
Смешанный вопрос с приветствием сохраняет обычную проверку источников;
карточка, план и прогресс не меняются от обычных реплик.
