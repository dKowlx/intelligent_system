# Project Navigator: описание приложения

Project Navigator — веб-приложение для индивидуальных учебных, рабочих
и личных проектов. Python-пакет называется `studynavigator`.

[Сервис](https://navigator.136-234-80-52.sslip.io/) ·
[Репозиторий](https://github.com/dKowlx/intelligent_system)

## Назначение и сценарий

Пользователь добавляет текст или PDF, подтверждает карточку проекта,
проверяет действия и задаёт доступность по дням. Приложение рассчитывает
расписание, показывает дефицит времени и сохраняет прогресс.

Карточка содержит цель, результат, требования, критерии и срок.
Действия содержат связи с требованиями, ожидаемый результат, признак
готовности, оценку с основанием, подшаги, приоритет и зависимости.
Неизвестный срок остаётся `null`; пользовательские дополнения отделены
от сведений источника. Фактическое время хранится отдельно от оценки.

Разделы интерфейса: «О проекте», «Ассистент», «Обзор», «Действия и план»,
«Аналитика». Маршрут доступен как схема зависимостей или список.
Поддерживаются светлая, тёмная и системная темы.

Ассистент отвечает по материалам, плану и аналитике со ссылками на источники.
Изменения плана сохраняются отдельным применением проверенного предложения.
История разговоров хранится на сервере в пределах проекта и браузерной сессии.

## Реализация

Стек: Python 3.12, FastAPI, Pydantic, SQLite/FTS5, pypdf,
HTML, CSS и JavaScript. Карточки, планы, прогресс и разговоры хранятся
в SQLite; оригиналы загрузок — в файловом каталоге.

Собственные MCP-клиент и сервер общаются по stdio. Инструменты
`list_assignments`, `get_assignment` и `search_materials` читают сведения
в области доступа текущей браузерной сессии.

LLM через API предлагает карточку и действия, формирует ответы ассистента.
Backend проверяет схемы, источники и зависимости; Python рассчитывает
суммы, дневные бюджеты и дефицит. API-ключи хранятся на сервере.
Ручной путь и offline-режим доступны без подключённой модели.

Исследовательская библиотека использует FTS5 и embeddings в SQLite;
при недоступности векторного поиска остаётся FTS5 с явным статусом.
Общая теория загружается через MediaWiki API и сохраняется с происхождением.
Эти материалы не задают требования пользовательского проекта.

Сохранение учитывает версии записей. Изменение карточки помечает прежний
план устаревшим. Завершённые действия учитываются при пересчёте остатка;
фактические минуты не считаются автоматическим подтверждением завершения.

## Границы

Один пользователь и один проект в фокусе. Поддерживаются текст и 1–3 PDF
с текстовым слоем: до 10 MiB, 100 страниц и 100 000 извлечённых символов
суммарно с текстовыми материалами проекта.

Планирование использует дневные бюджеты, резерв и зависимости.
Конкретные часы начала и окончания не назначаются. Нет командной работы,
аккаунтов, восстановления анонимной сессии, календарных интеграций,
уведомлений, OCR, DOCX и интеграции с LMS.

Доступ разделён браузерной cookie. При её утрате доступ к приватным
проектам из другого браузера не восстанавливается.
Связь действия с требованием проверяется структурно; готовность результата
подтверждает пользователь.

## Запуск и проверки

Команды запуска и настройки приведены в [README](../README.md).
Локальный запуск: `uv sync --locked --extra dev`, затем
`.venv/bin/python -m studynavigator`. Режим по умолчанию — `offline`.
Для `live` задаются `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`
и `STUDYNAV_MODE=live`.

Размещение использует Docker Compose, постоянный том данных и Caddy HTTPS.
Тесты приложения запускаются командой
`.venv/bin/python -m pytest tests/app -q`, веб-проверки —
`node --test tests/web/*.cjs`. Offline Eval запускается через
`tools/run_app_eval.py` и не проверяет подключённую модель.
