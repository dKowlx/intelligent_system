## Проверки

| Область | Подтверждение |
|---|---|
| Воспроизводимость | Запуск по README в отдельной среде |
| MCP | Обмен между клиентом и сервером |
| Offline | Результаты тестов с обозначенными подменами |
| Подключённая модель | Фактический вызов и полученный ответ |
| Хостинг | Публичная ссылка и выполненный сценарий |
| Сохранность данных | Повторное чтение данных после перезапуска |

Результаты относятся к конкретному запуску и конфигурации. Не подменяй
реальный вызов модели результатом mock. Технические ограничения описывай
как свойства реализации, без оценки действий команды и списка пожеланий.
