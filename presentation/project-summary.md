# Project Navigator

Project Navigator — веб-приложение для планирования учебных, рабочих и личных проектов. На основе PDF и текстового описания оно формирует цель, требования, критерии результата и действия с подшагами. Для каждого действия сохраняются приоритет, зависимости, ожидаемый результат и условие завершения.

## Что реализовано

- Загрузка PDF с текстовым слоем и добавление текстовых материалов.
- AI-разбор с подтверждением карточки пользователем.
- Декомпозиция, горизонтальная схема маршрута и расписание с учётом доступности и резерва.
- Ассистент с источниками, историей диалогов и подтверждаемыми изменениями плана.
- Сохранение прогресса и аналитика выполнения.
- Собственные MCP-клиент и сервер, FastAPI, SQLite, HTML/CSS/JavaScript.
- Размещение через Docker Compose и Caddy HTTPS.

## Как работает

Материалы сохраняются на сервере и доступны через MCP. Модель формирует структурированную карточку проекта. После её подтверждения алгоритм распределяет действия по доступным дням с учётом зависимостей. Изменения плана и прогресс сохраняются в SQLite. Пользователь обсуждает текущую работу с ассистентом и подтверждает предложенные изменения.

## Результат проверки

В новом проекте на опубликованном сервисе обработан документ «Личный проект.pdf». Получены **7 требований, 5 критериев, 5 связанных действий и 17 подшагов**. Сверка с предварительно составленным списком подтвердила наличие основных технических результатов: постановка задачи и MVP, MCP и LLM, интерфейс и хостинг, Eval, README и публичный репозиторий. Неизвестный календарный срок оставлен пустым.

Карточка подтверждена без ручной правки ответа модели. Расписание рассчитано и сохранено на сервере. Проверены фактический AI-разбор и сохранённый результат.
